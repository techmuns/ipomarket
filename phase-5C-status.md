## 3. What CI will do differently

The sandbox is intentionally unable to reach the public web or launch Chromium. The four sandbox RED outcomes are infrastructure-level (no egress / no Chromium), not Chittorgarh / Zerodha / Upstox availability calls.

In CI (`phase-0-probes` workflow, run with `group=J` or no input):
1. **P-25** will GET `https://www.chittorgarh.com/ipo/` from GitHub Actions egress. Per existing P-20 evidence the GMP page is reachable from GH Actions; the IPO list page is expected to behave similarly. Two detail URLs will be discovered and fetched. Outcome will be GREEN (all reachable + ≥ 2 detail URLs picked) or YELLOW (partial) — RED only on a real challenge / 403.
2. **P-26** will then read the captured HTML and report per-field extraction precision against the 10 expected fields. The §Y.9.1 precondition-3 threshold is **≥ 0.80**.
3. **P-27 / P-28** will re-run the existing P-23a / P-23b broker-page probes with Chromium installed (workflow step already does `npx playwright install --with-deps chromium`). Outcome should match P-23a / P-23b's GREEN baseline.
