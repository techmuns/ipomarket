## 4. Cover-extraction before / after

### Before (Gate B, commit `8ed2bfb`)

```json
"registrar": {
  "value": "NAME OF THE REGISTRAR CONTACT PERSON EMAIL AND TELEPHONE",
  "page": 2,
  "confidence": "high"
}
"brlms": {
  "value": [
    "LOGO OF THE BRLM NAME CONTACT PERSON TELEPHONE AND EMAIL",
    "IIFL Capital Services Limited Gaurav Mittal / Tel: +91 22 4646 4728",
    "(formerly known as IIFL Securities Limited) Pawan Kumar Jain E-mail: ihl.ipo@iiflcap.com",
    "InCred Capital Wealth Portfolio Harish Mallawat / Tel: +91 22 4161 1500",
    "Managers Priva"
  ]
}
```

`overall_confidence: "medium"`, `manual_review_required: false` (misleadingly).

### After (Phase 5A.1 — expected on CI re-run)

The Python heuristic fixes will:
- Reject `"NAME OF THE REGISTRAR..."` via `_HEADER_BLOCKLIST` and the `_FIRM_SUFFIX` requirement → registrar falls back to a non-header capture (e.g. `"KFin Technologies Limited"`) OR returns `null`.
- Reject `"LOGO OF THE BRLM..."` via `_HEADER_BLOCKLIST` and the all-caps-without-firm-suffix branch.
- Trim contact info from each BRLM line at `Tel:` / `E-mail:` / `Contact Person` boundaries, leaving e.g. `"IIFL Capital Services Limited"` and `"InCred Capital Wealth Portfolio Managers"`.
- Reject `"(formerly known as IIFL Securities Limited)..."` via the parenthetical-continuation rule.
- Set `needs_manual_review: true` if anchors matched but extraction returned `null`.

Sandbox cannot exercise this directly (InCred PDF 403'd; no extractor ran). CI Gate B re-run will produce the actual before/after diff against the InCred DRHP.
